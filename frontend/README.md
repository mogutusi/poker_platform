### Tech stack:

- **Next.js 14** 
- **React 18** 
- **TypeScript** 
- **Tailwind CSS** 
- **Lucide React** 

### Install dependencies
```bash
npm install
```

### Start

```bash
npm run dev
```

### Type check
```bash
npm run type-check
```

### Code check

```bash
npm run lint
```

## Environment setup

create `.env.local` and set up followings:

```env
NEXT_PUBLIC_API_URL=http://localhost:8000
NEXT_PUBLIC_WS_URL=ws://localhost:8000/ws
```
